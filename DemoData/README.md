# 演示历史数据

此目录中的记录全部为虚构内容，仅用于录屏和产品演示，不包含真实项目或个人信息。

## 推荐使用方法：完整演示模式

双击项目根目录下的 `start_demo.bat`。

它会使用独立的演示数据库启动应用，自动显示三个按生活领域划分的便签：

- 工作
- 学习
- 生活

便签表示需要独立显示/隐藏的大领域，标签表示领域内的具体项目或类型。
因此「工作」只有一张便签，其中通过「客户A项目」、「客户B项目」和「日常工作」
标签区分不同工作项目。

分析页会同时读取 `WorkplaceDoneList` 中的虚构历史归档。它不包含金融、证券、投行、律师或真实公司特征。演示模式使用项目内独立的 `APPDATA`，不会读取或修改真实用户数据库。

## 只切换分析数据

1. 正常启动桌面悬浮备忘。
2. 打开「已完成历史」。
3. 点击归档路径右侧的「更改」。
4. 选择本目录下的 `WorkplaceDoneList` 文件夹。
5. 点击「分析」，即可看到演示数据。

演示数据覆盖 2026 年 6 月至 8 月，包含多个便签、标签、完成日期、专注时长和复盘备注，可展示：

- 全部 / 近 7 天 / 近 30 天 / 本月 / 今年筛选
- 便签与标签联动筛选
- 完成数量、活跃天数、专注时长、涉及标签
- 深浅不同的完成热力图
- 按天完成清单、复盘备注和专注时长徽标

录屏结束后，退出演示程序，再使用原来的 `start.bat` 启动，即可回到真实数据。不要把演示目录与真实 `DoneList` 合并。
